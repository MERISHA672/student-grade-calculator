# Student Grade Calculator

A simple web application for calculating student academic performance.

## Features

- Enter marks for different subjects
- Calculates total marks
- Calculates average
- Automatically assigns a grade
- Displays pass or fail status
- Simple and responsive interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## What I Learned

- JavaScript functions
- Variables
- Conditional statements
- DOM manipulation
- Basic responsive web design
